# 素材与合规（交付前必读）

> 主文件按需指到这里。**这不是"建议"，是交付门槛。**

**封底自动输出的两行声明（资料来源 / 非官方粉丝作品 · 仅供个人收藏）不要删**——由 build 脚本写入，不依赖使用者是否填 `credits`。

> 仓库根还有一份 `DISCLAIMER.md`（给 clone 的人看的第一眼声明）：工具是 MIT，但**产物里的素材权利属于原作者**，公开与商业使用需自行取得授权。`npm run cards` 导出分享卡时也会就这点再提醒一次。

## 逐条底线

- **只做个人收藏**：海报、立绘、截图的版权属原作者与各制作委员会。个人自用通常可以；**公开发布（发群、上传平台、印制售卖）必须自行取得授权**——注明来源不能替代授权
- **文字必须重写**：`synopsis` / `unit_synopses` / `watch_order` 一律自己组织语言，**不得逐句搬运**维基百科、萌娘百科、官网原文（事实不受保护，但表述受 CC BY-SA 一类许可约束）。写完抽一句回搜，命中原文就改
- **只用全年龄素材**：命中 R-18 / 擦边 / 性化未成年角色的素材**一律弃用换源**（`npm run candidates` 已在查询里排除 explicit/questionable，但那只是兜底，最终以目视为准）。这类内容的法律后果是**刑事级**的，远重于版权
- **不用同人图**（授权链条不清、质量不可控）、**不收录真人素材**（声优照片等涉及肖像权）
- **不伪装官方**：封面不用官方 logo，不写"官方/正版"，封底的「非官方粉丝作品」声明保留
- **字体署名保留**：缺省的霞鹜文楷为 SIL OFL 1.1，要求版权声明随字体分发，封底那行不是可选装饰；**换了字体就要同步改 `config.json` 的 `credits`**（换成别的商业字体前先确认它允许嵌入与再分发——很多不允许）。组件与字体义务见 `../THIRD_PARTY_NOTICES.md`
- **取图走官方渠道优先**：动画官网 / 官方 X / 发行方 / 原作出版社 → AniList、Bangumi 条目图 → safebooru **仅作候选对比兜底**（选中后尽量回溯官方原图）。渠道顺序与理由见 `image-selection.md`

## 来源台账（把合规变成产物）

`npm run sources` 会导出 `anime_build/_sources.md`：每张图的渠道、出处 URL、取得日期。

- `fetch_candidates.js --pick` **自动**记一条图库来源
- 官方渠道取到的图用 `npm run sources -- add --work <作品名> --kind cover --channel official --url <出处页面>` 手工记
- 台账按「作品 + 用途」去重、**后来者覆盖**——它回答的是"最终交付用的是哪张、来自哪"
- 公开分享或被人质疑时，这份台账就是你的自证材料（**它证明来源，不等于授权**）

## 外发前清理（隐私）

把项目文件夹拷给别人、上传网盘或打包分发前，删掉这三样：

| 删什么 | 为什么 |
| --- | --- |
| `scripts/config.json` | 含你的**本机绝对路径**（用户名） |
| `names.txt` | 你的片单 ＝ 观看偏好 |
| `anime_research/` | 调研稿与从网上抓下来的图片 |

它们都不在版本库里（见 `.gitignore`），**但手动"拷贝整个文件夹"时会一起被带走**。

台账不再是隐私项：`npm run sources` 导出的 `_sources.md` 只含生成日期与条目，**不写本机绝对路径**（`pack` 复制台账时还会再做一层兜底清理）。

另外注意交付包现在含 `anime_build/covers/`——那是 HTML 用相对路径引用的封面图（第三方素材），`pack` 会一并打进 `_deliver/`；外发时它和 `anime_research/` 里的图一样，要按"仅个人收藏"的标准确认授权。

顺带一个好消息：**交付物本身是干净的**——实测 `<书名>.html` 与 `.pdf` 的正文及元数据都不含本机路径或用户名（`npm run check` 不管这个，它查的是产物完整性与页码）。

## 交付说明里的核验状态

`npm run pack` 生成的交付说明带一节**核验状态**，把"机器验过的"（产物断言 `[C1]-[C17]`、数据完备度 `[A1]-[A10]`）与"agent 声称看过的"（全页目检、封面目检）分开放。合规上要紧的是：**没做的环节会留在纸上**——签署用 `npm run pack -- --pages-reviewed --covers-reviewed`，没签就写「未声明」。**不要删掉那一节再去对外声称全书已核验。**
